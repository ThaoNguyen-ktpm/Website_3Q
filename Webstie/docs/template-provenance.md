# Foundation reference

Official reference: https://github.com/fastapi/full-stack-fastapi-template

Inspected revision: b1125d8839482cb7bbae603ddc6d0081bf87532e

This project is a fresh, minimal vertical slice following the FastAPI / PostgreSQL / React architecture. It is not a cloned or fully configured template. No upstream default passwords, deployment workflow, mail server or public routing was copied. Python 3.9 is the Mac-provided interpreter, so compatible dependency versions are locked separately.
